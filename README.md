# 💼 Personal Portfolio Website

## 🎯 Objective
I developed a **personal portfolio website** using **HTML**, **CSS**, and **JavaScript** to showcase my **projects, skills, education, and achievements**.  
The website serves as a digital resume that highlights my professional journey and technical abilities.

---

## ✨ Features
- 🏠 **Home Section** – Provides an introduction and highlights who I am.  
- 👨‍🎓 **About Section** – Shares details about my background, education, and interests.  
- 💻 **Projects Section** – Displays my projects with short descriptions and live/demo links.  
- 🛠️ **Skills Section** – Lists my technical skills in web development and programming.  
- 📞 **Contact Section** – Allows visitors to reach me through a contact form or social links.  

---

## 🧰 Tech Stack
- **HTML** – Structure and layout of the website  
- **CSS** – Styling and responsive design  
- **JavaScript** – Interactive functionality and dynamic content
